# Synthetic face-detection sample

`cctv-face-sample.webm` is an AI-generated portrait of a fictional adult,
converted into a short local WebM clip for demonstrating face **detection**.
It does not depict an identified real person and is not live CCTV. The clip
contains an embedded synthetic-test label.

No identities, biometric embeddings, face galleries or demographic labels are
provided. This single frontal example is not a performance or fairness benchmark;
actual recordings may contain missed detections and false positives.

The Tiny Face Detector model and its MIT licence/provenance are located in
`../models/face-detector/`. Use only footage you are authorised to process.
